# The programme on this canvas

`programme.m4a` is 45 seconds of

**Apathy And Resignation Are The Sources Of Our Misfortune** — Citizens Of The
Empire, *Citizens of the Empire* (2010), **CC BY 3.0**.

- Licence: <https://creativecommons.org/licenses/by/3.0>
- Artist: <https://citizensoftheempire.bandcamp.com/>
- The file, and where the licence is stated:
  <https://commons.wikimedia.org/wiki/File:Citizens_Of_The_Empire_-_03_Apathy_And_Resignation_Are_The_Sources_Of_Our_Misfortune.flac>

`programme.oaaz` is what Open Audio Analyzer's engine measured while that
excerpt played, written by `npm run record`. It is a measurement of the track
rather than the track, and it is under this repository's own licence.

CC BY asks for credit wherever the audio is published. The front page carries it
under the canvas, this file travels with the audio into every build, and
`tool/fetch_test_audio.dart` in the repository root says the same about the
source it came from. There is no non-commercial and no share-alike clause.

The excerpt is committed — unlike the album it is cut from, and unlike the
renderer's copy — because the site is deployed by CI now, and no job in this
repository fetches 35 MB of somebody else's music to publish a page.
