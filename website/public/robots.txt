# Crawl everything, and here is the sitemap.
#
# `User-agent: *` below already says yes to every crawler there is, so the named
# groups that follow it change nothing today. They are here because a crawler
# reads exactly **one** group — the most specific one that matches its name —
# and never merges it with `*`. That rule cuts both ways, and both directions
# are the reason this file is no longer four lines:
#
#   - A future `Disallow:` added to `*` would silently stop applying to every
#     agent named here. If you narrow `*`, narrow these too, or you have written
#     a rule you believe covers everything and that the twelve most consequential
#     crawlers ignore.
#
#   - Conversely, an assistant that is told nothing about itself falls back to
#     `*`, and a site that only ever says `*` has never actually stated a policy
#     on AI — it has only failed to have one. This project is GPL-3.0-or-later
#     and its whole point is to be found by somebody looking for a free loudness
#     meter. Being read, quoted and summarised is the distribution channel, not
#     a cost to be tolerated.
#
# Two of the names below crawl nothing. `Google-Extended` and
# `Applebot-Extended` are control tokens: Googlebot and Applebot have already
# fetched the page, and these say whether Gemini and Apple Intelligence may use
# what was fetched. A group for them is a grant of *use*, not of access.
#
# **This file is only half of it.** Cloudflare can refuse an AI crawler at the
# edge, before the request reaches the Worker that serves these bytes, and a
# managed rule can be turned on for a zone without anything in this repository
# changing. robots.txt would then be publishing a permission the site does not
# honour. The check is a request wearing the agent's name:
#
#   curl -so /dev/null -w '%{http_code}\n' \
#     -A 'Mozilla/5.0 (compatible; GPTBot/1.2; +https://openai.com/gptbot)' \
#     https://open-audio-analyzer.com/
#
# 200 on 2026-09-12 for GPTBot, ClaudeBot, OAI-SearchBot and PerplexityBot.
#
# `/analyzer/` is deliberately **not** disallowed to anyone, here or below. It
# is the compiled demo the front page loads into an iframe, it carries
# `noindex`, and a disallowed URL is never fetched — so the refusal would never
# be read and the address could stay indexed on the strength of a link alone.
# It is 6.8 MB of Flutter with no prose in it, which is a fair argument for
# keeping a crawler out; it is not a good enough one to hide the `noindex` that
# is doing the actual work.

User-agent: *
Allow: /

# OpenAI. Three agents, three different things: GPTBot trains, OAI-SearchBot
# builds the index ChatGPT search answers from, and ChatGPT-User is the live
# fetch made when somebody asks about this page by name.
User-agent: GPTBot
User-agent: OAI-SearchBot
User-agent: ChatGPT-User
Allow: /

# Anthropic, split the same way. `anthropic-ai` and `Claude-Web` are retired
# names kept because a retired crawler is not the same as a crawler that has
# stopped reading its old name.
User-agent: ClaudeBot
User-agent: Claude-SearchBot
User-agent: Claude-User
User-agent: anthropic-ai
User-agent: Claude-Web
Allow: /

# Perplexity: the index, and the fetch it makes while a person waits.
User-agent: PerplexityBot
User-agent: Perplexity-User
Allow: /

# Control tokens, not crawlers — see the note above. Gemini and Apple
# Intelligence may use what Googlebot and Applebot already have.
User-agent: Google-Extended
User-agent: Applebot-Extended
Allow: /

# Meta AI: the crawler, and the fetch made on a user's behalf.
User-agent: meta-externalagent
User-agent: meta-externalfetcher
Allow: /

# Common Crawl. Not an assistant at all — an open corpus that a great many
# models are trained on, including some that will never announce themselves
# here. It is the one entry that pays off years after the fetch.
User-agent: CCBot
Allow: /

# The rest of the field, named so that narrowing `*` does not quietly exempt
# them: Mistral, DuckDuckGo's assistant, Amazon and ByteDance.
User-agent: MistralAI-User
User-agent: DuckAssistBot
User-agent: Amazonbot
User-agent: Bytespider
Allow: /
